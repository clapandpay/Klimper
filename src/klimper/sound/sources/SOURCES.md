# Sources of the Klimper sound

Recordings the rattle loops and knocks are cut from (`scripts/klimper-sound.py`). All are
**CC0 1.0 (public domain)** by Kenney Vleugels, kenney.nl, converted here to mono 44.1 kHz
16-bit WAV and otherwise untouched. No attribution is required by the licence; this file is
the attribution anyway.

| File                        | Pack (kenney.nl)    | Original                     |
| --------------------------- | ------------------- | ---------------------------- |
| `kenney-handle-coins.wav`   | RPG Audio (CC0)     | `handleCoins.ogg`            |
| `kenney-handle-coins-2.wav` | RPG Audio (CC0)     | `handleCoins2.ogg`           |
| `kenney-metal-light-0.wav`  | Impact Sounds (CC0) | `impactMetal_light_000.ogg`  |
| `kenney-metal-light-2.wav`  | Impact Sounds (CC0) | `impactMetal_light_002.ogg`  |
| `kenney-metal-medium-1.wav` | Impact Sounds (CC0) | `impactMetal_medium_001.ogg` |
| `kenney-metal-heavy-0.wav`  | Impact Sounds (CC0) | `impactMetal_heavy_000.ogg`  |

The ding (coins arrive) is synthesised by the same script and has no recorded source.
