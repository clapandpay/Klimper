# Klimper 1.0.0

**Clap and Pay.** The first public release of Klimper, a minimal, non-custodial Chia wallet
for the phone, built on the [Sage](https://github.com/xch-dev/sage) engine (Sage v0.13.1).

Tag: `klimper-v1.0.0`. Klimper numbers its own releases; the Sage version under it is shown
next to it in Settings.

## What Klimper is

- **Your keys, on your phone.** Klimper is non-custodial: the recovery words and keys never
  leave the device, and there is no Klimper account or server holding your money.
- **Pay and receive XCH and CATs**, with `@handle` names from XCHandles in the send screen,
  and your own handles shown under the total.
- **The wallet's total** on top of your assets, as an estimate in USD and XCH. Prices come
  from nodexch.com.
- **One Scan tab** for every code: an address, an offer, or a website's connection code.
- **Connect to websites with Xchonnect.** A website asks, Klimper shows exactly what will be
  signed and what leaves the wallet, and nothing is signed without your approval. Per-site
  permissions and spending limits; spends whose conditions the signature does not fix are
  refused. Websites can ask the wallet to take an offer or make one.
- **Push wake-ups** for website requests. The notification carries nothing; Klimper reads
  the request itself.
- **Coins that feel like coins**: a coin sound when money arrives, coins you hear and feel
  when you shake the phone, and a coin pouch on each token page that shows your coins as
  they are, with split and combine.
- **Privacy mode** hides every amount.
- **The full wallet on the desktop.** On macOS, Linux and Windows every feature is on:
  offers, swap, options, NFT minting, profiles, token issuing, WalletConnect, the RPC
  settings, the theme gallery and Sage apps, which run in Klimper because the app bridge is
  unchanged.
- **On the phone, everything but offers and apps.** iPhone and Android have the same
  features as the desktop except offers and Sage apps.

## New since 0.2.6

- **Xchonnect 0.1.0.** Klimper now uses the released Xchonnect crates instead of the
  release candidate. Amounts and times in a request are read as Xchonnect 0.1.0 writes them.
- **Websites can make offers** (`chia_createOffer`): XCH, CATs and options, built from the
  wallet's coins and signed after your approval. Nothing is broadcast.
- **An offer an agent makes is kept in Klimper**, like an offer you made yourself.
- **Prices from nodexch.com only**, with CoinGecko and dexie as the fallback.
- **A new logo** in the app icon and in the light and dark themes. The "Colorful" theme is
  gone.
- **Fixed:** the theme picker no longer crashes when no theme was used before.
- **Features per platform.** The desktop builds turn every feature on; the phone builds
  everything except offers and Sage apps.
- **"Use my Clap and Pay money" is removed** from the start screen.
- **From Sage:** tooltips in the sandbox no longer clip, and `chia_updateCat` for
  WalletConnect, so a website can suggest a name for a token.
- **Dependencies** updated, with the open security advisories patched.
- **Open source.** Klimper now lives in its own public repository. Every file of ours
  carries an SPDX licence header, every changed Sage file says what was changed, and
  licences are checked with cargo-deny.

## Install

- **iPhone:** through TestFlight, then the App Store.
- **macOS, Linux and Windows:** the installers are attached to this release: `.dmg` for
  macOS (Apple silicon and Intel, signed and notarized), `.deb`, `.rpm` and `.AppImage` for
  Linux and `.msi` and `.exe` for Windows, each for x64 and ARM64. Linux and Windows are not
  signed yet:
  - **Windows:** at the SmartScreen warning, choose "More info", then "Run anyway".
- **Android:** build from source (`README.md`, "Build").
