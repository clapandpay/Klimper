# Klimper 1.1.0

Tag: `klimper-v1.1.0`. Klimper numbers its own releases; the Sage version under it (Sage
v0.13.1) is shown next to it in Settings.

## New since 1.0.0

- **Websites can make partial offers** (`chia_createPartialOffer`, CHIP-0052). A website
  such as Pengui asks for an offer that takers can fill in parts: what it gives, what it asks,
  the least one fill pays, an optional fee every fill pays and an optional expiry. Klimper
  builds and signs the whole partial offer in the wallet after one approval, which shows it
  as a partial offer with those terms, and hands back only the `partial1…` text. Nothing is
  broadcast, and the one-sided offer it starts from never leaves the wallet. The offer is
  kept in the wallet's own partial offers. Existing connections that may send get the method
  once, without pairing again.
- **Partial offers in the wallet** (view, take an amount, make, list and cancel), behind a
  feature flag that is still off in the release builds.
- **An agent's offer expires when it asked**: the `expiresAt` of `chia_createOffer` is
  asserted by every spend of the offer.

## Install

- **iPhone:** through TestFlight, then the App Store.
- **macOS, Linux and Windows:** the installers are attached to this release, as for 1.0.0
  (`docs/releases/1.0.0.md`, "Install").
- **Android:** build from source (`README.md`, "Build").
