## Default Permission

Status, enrolment, unlock, lock and removal of the Klimper passkey, and erasing the keys when the passkey is lost.

#### This default permission set includes the following:

- `allow-status`
- `allow-enroll`
- `allow-unlock`
- `allow-lock`
- `allow-remove`
- `allow-erase`
