## Default Permission

The Klimper card through Gnosis Pay: the card address of the open wallet.

#### This default permission set includes the following:

- `allow-card-status`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`klimper-card:allow-card-status`

</td>

</td>
</tr>

<tr>
<td>

</td>
